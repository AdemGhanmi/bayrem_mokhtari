# Coach Bayrem Mokhtari — cinematic multi-page website

Static HTML/CSS/JS website inspired by the editorial structure and responsive navigation approach of iamjosemourinho.com, but with original Bayrem content/layout and the supplied project assets.

Pages:
- index.html
- story.html
- career.html
- honours.html
- journal.html
- gallery.html
- contact.html
- sources.html

Languages:
- EN / FR / AR via the top-right language switcher (saved in localStorage)
- Arabic automatically switches document direction to RTL.

Media:
- assets/video/b1.mp4 is the local video supplied in the project.
- YouTube and Facebook links point to the URLs supplied by the site owner.

Career data:
- The chronology follows the published Bayrem Mokhtari biography and includes source links.
- Some historical role/date details should be confirmed by the coach before being presented as an official CV.

Important:
- Third-party photos, club logos and external media may require permission/licensing for public or commercial publication.
- The site intentionally includes a Sources & Credits page.
